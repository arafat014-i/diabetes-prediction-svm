# Diabetes Prediction Using SVM

## Overview

This project uses a Support Vector Machine (SVM) machine learning algorithm to predict whether a person is likely to have diabetes based on medical diagnostic features.

## Dataset

The dataset contains several medical diagnostic features, including:

* Pregnancies
* Glucose
* Blood Pressure
* Skin Thickness
* Insulin
* BMI
* Diabetes Pedigree Function
* Age

The target variable is `Outcome`.

* `0` → Non-diabetic
* `1` → Diabetic

## Technologies Used

* Python
* NumPy
* Pandas
* Scikit-learn
* Google Colab
* Support Vector Machine (SVM)

## Machine Learning Workflow

1. Load the dataset
2. Explore the dataset
3. Separate features and target
4. Split the dataset into training and testing data
5. Standardize the features using `StandardScaler`
6. Train the SVM classifier
7. Make predictions
8. Evaluate the model using accuracy score

## Project Files

* `diabetes_prediction_svm.ipynb` — Jupyter/Google Colab notebook containing the complete project
* `dataset.csv` — Dataset used for training and testing

## Model

The project uses the Support Vector Machine (SVM) classifier provided by Scikit-learn.
